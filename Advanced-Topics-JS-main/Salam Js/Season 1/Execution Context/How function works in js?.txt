Whenever Js runs any program,an global execution context is created.It will have two phases 
a)variable environment      b)Thread of execution
Now before executing single line of code,memory will be allocated in first phase  see image(Executon Context 3.png).
Now also understand concept of call stack with it. Call stack is a stack where all the execution stacks are kept.So when our global execution context is created,it is pushed inside a stack.See image(Execution context 4.png).Now our global exection context is pushed in call stack.Now the actual time come when the code is going to be execute.
