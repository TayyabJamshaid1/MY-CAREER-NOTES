=>What is Named Function Expression?

var a =function bcd(){
        console.log("HI");
}
this is very weird but u can do it in js
a();  //HI
bcd();//Reference error:bcd is not a function //u cannot call directly bcd in named function Expression
Reason why we cannot call directly bcd()?
Because when u assign a value to function,Js does not consider it as a function,it consider it as a local value.So it is not in its outer/global scope(Means when execution context created,this function is not in its memory,when program run in thread of execution,this function is treated as a local value)

As we say,it is treated as a local value so we can access it in function but cannot call it in a function because ye loop me chla jai ga ,bar bar khud ko he call krta jai ga
