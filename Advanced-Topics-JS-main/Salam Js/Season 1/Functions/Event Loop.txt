As we discuss microtask is given priority.So,we will discuss what will come in microtask quene?

"All the callback functions which come through promises will go in micro task quene and there is something known as mutation observor.So mutation observor basically keeps  on checking whether there is some mutation in dom tree or not.If there is mutation in dom tree,it can execute some callback functions.So These two thing callback function which coming through promises and as well as mutation observor goes inside the microtask quene.All everything other like callback functions which comes from setTimeOut,dom apis,event listners & all will go in callback quene.Callback quene is also known as task quene.Suppose there are 3 tasks pending in micro task quene and one task pending in callback quene.So in this case,event loop will only give opportunity to call back quene tasks when once all the tasks in micro task quene has been completed."

What is Starvation?
As we know,event loop give first chance to micro task quene.So suppose,we have  tasks in micro task quene and in callback quene.Suppose,in micro task quene,one task on execution create another micro task and that task create another micro task and etc.,so in that case task in call back quene will never get a chance to execute because micro tasks have more priority.That means there is a possibility that task waiting in callback quene,will never get a chance to executed for a long time.So it is known as starvation of call back quene
