=====>BOX SHADOW

Scenario 1:
=> first parameter belongs to x-axis(horizonatal),second parameter belongs to y-axis(vertical).By default ,x axis with positive value is on right side and y axis with positive value is on bottom side. 
*{
margin: 0;
padding: 0;
box-sizing: border-box;
}

.container{
  background-color: aqua;
  border:3px solid black;
  height:600px;
  display: flex;
  justify-content: center;
  align-items: center;
}

.box{
  background-color: aquamarine;
  width: 330px;
  height: 430px;
  border: 1px solid green;
    display: flex;
    flex-direction: column;
  justify-content: center;
  align-items: center;
  box-shadow: 10px 20px red; 
}
p{
  text-align: center;
}


Scenario 2:
If first parameter gives negative value,it moves on left ,similarly ,if second value gives negative value,it moves on top.


.box{
  background-color: aquamarine;
  width: 330px;
  height: 430px;
  border: 1px solid green;
    display: flex;
    flex-direction: column;
  justify-content: center;
  align-items: center;
  box-shadow: -10px -20px red; 
}


Scenario 3:
If third parameter is avaibale,it reflects blur effect and if fouth parameter is avaibale,it represents spread-radius


.box{
  background-color: aquamarine;
  width: 330px;
  height: 430px;
  border: 1px solid green;
    display: flex;
    flex-direction: column;
  justify-content: center;
  align-items: center;
  box-shadow: -10px -20px 10px 10px red; 
}

Scenario 4:
If inset is used,then shadow  andr ki trf aiy gi 
.box{

  width: 330px;
  height: 430px;
  border: 1px solid green;
    display: flex;
    flex-direction: column;
  justify-content: center;
  align-items: center;

}


Scenario 5:
If want to add multiple shadows,then use below syntax
