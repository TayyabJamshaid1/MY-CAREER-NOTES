Now if we want a 2D view,then we have to tell that how much rows and columns we required.
For this we can use grid -template-columns and grid template rows properties.

* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}

.container {
  width: 100vw;
 height: 100vh;
  padding:4rem;

 display: grid;
 row-gap: 5px;
 column-gap: 5px;
 grid-template-rows: 100px 100px;
grid-template-columns: 100px 100px 100px;
}
.item{

  background-color: green;
  border: 1px solid red;
}

More approriate way to make grid complex design by using grid-template-area


<body>
   <div class="container">
<div class="item header">Header</div>
<div class="item sidebar">Sidebar</div>
<div class="item main-content">Main Content</div>
<div class="item content2">Content 1 </div>
<div class="item content3">Content 2</div>
<div class="item footer">Footer</div>

   </div>
</body>
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
body {
  width: 100%;
  height: 100%;
}
.container {
  width: 100%;
  height: 100vh;
  display: grid;
  gap: 1rem;
  background-color: rgb(71, 65, 65);
  padding: 2rem;
 grid-template-areas: "header header header" 
 "sidebar maincontent maincontent" 
 "sidebar content2 content3" 
 "footer footer footer";
}
.item {
  border: 3px solid black;
  background-color: greenyellow;
  color: blue;
  padding: 1rem;
}
.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main-content { grid-area: maincontent; }
.content2 { grid-area: content2; }
.content3 { grid-area: content3; }
.footer { grid-area: footer; }
