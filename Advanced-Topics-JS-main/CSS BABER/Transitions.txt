Transition:
Changing element styling from one value to another.It works on triggered(jab b kisi element k upr hover/click wagaira hu,tab element k style update kr du).It works in single step.Animations mei b style ki property ki values update huti ha but diff is animation can work in multiple steps while Transition works in single step.See Diff btw animation & Transition.png image.In easy words,Ek animation mei multiple transitions huti ha but har transition me srf ek animation huti ha.U can say animation is a set of transitions

Example 1:
<body>
    <div class="container">
        <div class="box"></div>
      
    </div>
</body>


*{
margin: 0;
padding: 0;
box-sizing: border-box;
}

.container{
  background-color: aqua;
  border:3px solid black;
  height:100vh;
  width: 100vw;
}
.box{
  width: 350px;height: 80px; background-color: blue;border: 3px solid yellow;
  border-radius: 10px;
  margin: 10px;
  transition-property: all;
  transition-duration: 4s;
  transition-delay: 1s;
  transition-timing-function: linear;
}

.box:hover{
  width: 1200px;
  height: 300px;
  background-color: green;
}
