4-Order
The order property in Flexbox controls the visual order of individual flex items within a flex container

=>By default, all flex items have an order value of 0
=>Flex items with lower order values will appear earlier in the visual layout than those with higher order values.(agr - me koi order ha tu phly wo aiy ga,phr 0 waly jo by default ha and last pr jitna zyada order number huta jai ga wo sab sy agay ata jaiy ga)
=>You can use both positive and negative integers. For example, an item with order: -1 will appear before items with order: 0, and an item with order: 1 will appear after items with order: 0.

#box2{
  background-color: blueviolet;
    order: -1;    //box 2 sab sy ph
}
#box3{
  background-color: cadetblue;
  order: 400;
}

5-Flex grow 

The flex-grow property specifies how much the item will grow relative to the rest of the flexible items inside the same container.

1-If given equal value,then sab equal width k sath divide hu jai gi

margin: 0;
padding: 0;
box-sizing: border-box;
font-size: 10px;
}

  border: 5px solid red;
  height: 500px;
  display: flex;
  flex-wrap: wrap;
    /* align-content: center; */

  align-items: center;
}
.box{
  width: 200px;
  height: 200px;
  border: 2px solid brown;
}
#box1{
  background-color: aqua;
  flex-grow: 1;
}
#box2{
  background-color: blueviolet;
    flex-grow: 1;

}
#box3{
  background-color: cadetblue;
    flex-grow: 1;

}
#box4{
  background-color: chocolate;
    flex-grow: 1;

}

2-If given more value to any item,it will grow more relative to other items
#box1{
  background-color: aqua;
  flex-grow: 1;
}
#box2{
  background-color: blueviolet;
    flex-grow: 1;
}
#box3{
  background-color: cadetblue;
    flex-grow: 2;   //it will grow 2 times more then other items
}
#box4{
  background-color: chocolate;
    flex-grow: 1;
}
