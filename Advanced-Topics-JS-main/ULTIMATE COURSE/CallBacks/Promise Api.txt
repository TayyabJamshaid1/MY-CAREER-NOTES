Promise Api
It has some methods
1-Promise.all

let promise = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(5);
  }, 2000);
});
let another = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(7);
  }, 8000);
});
let promise3 = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(9);
  }, 3000);
});

let promises = Promise.all([another, promise, promise3]);  
promises.then((value) => {
  console.log(value);      [7,5,9]   //result is pattern sy aiy ga jo  promise.all me jis promise ko phly likha,usi ki value result ki array me phly aiy gi
});

Note:
Promise.all takes a iterateable(array) of promises and it runs all the promises in parallel.
It has a 2 scenarios

a)All the promises are successfully resolved
Promise.all will return an array with the value of all the results.
Promise.all will run all the promises in parallel but it wait for all of them to be finished
After all the promises are successfully resolved,it will collect all the results and give it inside an array and give it back to us.
In this scenario,Promise.all k successfully resolved ki total timing 8s hu gi kyu k sab sy late call usy he kya gya ha 

b)If any of these promise are failed or get rejected
As soon as any of these promises will get rejected,promise.all will throw an error.It will throw the same error which failed or rejected promise are returning to it.
It will not wait for other promises to get successfull or rejected.It will immedjiately throw the error as soon as as possible
Agr koi promise fail hu k ya reject hu k  error throw kr dta ha tu ye baqi promises k result ko b ignored kr k srf error he show krwaiy ga

2-Promise.allSettled
In case of any promise failed or rejected,it still wait for other promises to get settled.Settled means Whether they(other promises) are success or failed,it will give you all the results.
Agr kisi promise  me koi error aya b ha tu b hamaray dosary results ko show krwao along with that error
let promise = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(5);
  }, 2000);
});
let another = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(7);
  }, 2000);
});
let promise3 = new Promise(function (resolve, reject) {
  setTimeout(() => {
    reject(new Error("HI"));
  }, 2000);
});

let promises = Promise.allSettled([another, promise, promise3]);
promises.then((value) => {
  console.log(value);
});

4-Promise.any(seeking for first success)
It will wait for the first promise to get successfull 
or 
In any,u will wait for the first success/fulfilled/resolved.
It is same like race but the difference is that race me sab sy phly settled huny wala promise me agr error aiy tu wo error throw kr dta ha but any k case me agr error aya
tu us promise ko chor k agly resolve promise ka result show krwa dta ha.Let suppose agr 3no promise me he error a jai tu 3no errors ki collection bna k error throw kr dta ha.We can call this aggregate errors(collection of errors).Aggregate error only come in promise.any case.Remember,in Promise.allSettled,we get a error collection too but this error comes in .then in array,not in catch.

let promise = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(5);
  }, 2000);
});
let another = new Promise(function (resolve, reject) {
  setTimeout(() => {
    resolve(7);
  }, 4000);
});
let promise3 = new Promise(function (resolve, reject) {
  setTimeout(() => {
    // resolve(7);
    reject(new Error("New Error"));
  }, 1000);
});

let promises = Promise.any([another, promise, promise3]);
promises.then((value) => {
  console.log(value);
});

Aggregate error example:
let promise = new Promise(function (resolve, reject) {
    setTimeout(() => {
        console.log('promise');
        reject(new Error("HI"));
    }, 2000);
  });
  let another = new Promise(function (resolve, reject) {
    setTimeout(() => {
        console.log('another');
        reject(new Error("HI"));
    }, 2000);
  });
  let promise3 = new Promise(function (resolve, reject) {
    setTimeout(() => {
        console.log('promise3');
      reject(new Error("HI"));
    }, 2000);
  });
  
  let promises = Promise.any([another, promise, promise3]);
  promises.then((value) => {
    console.log(value);
  }).catch((err)=>{
    console.log(err.errors);
  })
