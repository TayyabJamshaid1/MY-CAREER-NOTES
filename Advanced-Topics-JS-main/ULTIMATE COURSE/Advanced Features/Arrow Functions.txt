OTHER DIFFERENCES btw arrow function vs regular function

1-Syntax differnce
2-Arrow functions lexically bind this (inherit from parent scope), whereas regular functions dynamically determine this based on their execution context."Dynamically determine this" means the value of this changes based on how the function is called.
Example:
function showCar() {
  console.log(this.model);
}

const car1 = { model: "Toyota", show: showCar };
const car2 = { model: "Honda", show: showCar };

car1.show(); // "Toyota" (this = car1)
car2.show(); // "Honda" (this = car2)


Memory Aid:

Regular functions: "How am I being called?" (dynamic)

Arrow functions: "Where was I born?" (lexical)
3-Arrow functions do not have their own arguments object. 

Example:
=>Arrow Function (no arguments object):

const showArgs = () => {
  console.log(arguments); // ReferenceError: arguments is not defined
};
showArgs(1, 2, 3);

=>Regular Function (has arguments object):

function showArgs() {
  console.log(arguments); // Arguments(3) [1, 2, 3, ...]
}
showArgs(1, 2, 3);


4-Arrow functions cannot be used as constructors with the new keyword while Regular functions can be used as constructors with new.

Example:

=>Arrow Function (cannot be used as constructor):

const Person = (name) => {
  this.name = name; // TypeError: Person is not a constructor
};
const john = new Person("John");

=>Regular Function (can be constructor):


function Person(name) {
  this.name = name;
}
const john = new Person("John");
console.log(john.name); // "John"

5-Arrow functions with a single expression can have an implicit return while Regular functions require an explicit return statement.

6-Arrow function do not have prototype property
 Prototype Property
Arrow Function (no prototype):

javascript
const foo = () => {};
console.log(foo.prototype); // undefined
Regular Function (has prototype):

function foo() {}
console.log(foo.prototype); // {constructor: ƒ}

=>Use regular functions when:

Defining object methods

Creating constructors
