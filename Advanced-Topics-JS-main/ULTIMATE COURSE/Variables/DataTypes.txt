Deep copy vs shallow copy
Example:
let data={amount1: 99, amount2: 77, amount3: 55}
 let data2=data;
 data2.amount2=99;
 console.log(data,data2);

Problem is that agr mai data2 me kuch change kr rha hu tu wo changes data me hu rhi ha ,aisa ni huna chahiye
To prevent from this behaviour, we use shallow copy and deep copy.Firstly we will discuss shallow copy

Shallow copy:
In this method,hamary pas object ka reference save huny ki bjaiy us ki values save huti ha.e.g data2 me phly data ka reference save huta tha,but ab is method sy us ki values save hu gi let data={amount1: 99, amount2: 77, amount3: 55}
 let data2=Object.assign({},data);
 data2.amount2=99;
 console.log(data,data2);  

1st way in Shallow copy: Object.assign
Example:
let data={amount1: 99, amount2: 77, amount3: 55}
 let data2=Object.assign({},data);
 data2.amount2=99;
 console.log(data,data2);

2nd way in Shallow copy: destructuring
Example:
let data={amount1: 99, amount2: 77, amount3: 55}
 let data2={...data}
 data2.amount2=99;
 console.log(data,data2);

 WHAT IS THE PROBLEM WITH SHALLOW copy
 shallow copy me problem ye ha k agr ek object me agr humny dosra object bna dia tu us inner object me ki gai changes sary other assign objects me a jai gi

TO RESOLVE THIS PROBLEM WE USE DEEP COPY

Functions and Array behaviour in Shallow Copy
let data = { arr: [1, 2, 3] };
let data2 = { ...data }; // shallow copy

// Mutating nested array
data2.arr.push(4);

console.log(data.arr);  // [1, 2, 3, 4] (also changed)
console.log(data2.arr); // [1, 2, 3, 4]


👉 The array is shared by reference, so both objects see the change.

Breaking the Link with Reassignment
let data = { arr: [1, 2, 3] };
let data2 = { ...data };

// Reassign to a new array
data2.arr = [44, 78, 99];
or
data2.arr=[...data.arr]

console.log(data.arr);  // [1, 2, 3]
console.log(data2.arr); // [44, 78, 99]


👉 Reassigning creates a new reference, so the original stays safe.

3. Copying Functions

Functions are also objects in JavaScript, so they are copied by reference.

let data = {
  func: function() { return "hi"; }
};

let data2 = { ...data }; // shallow copy

console.log(data.func === data2.func); // true (same reference)


Both objects share the same function reference initially.

Unlike arrays, functions are not typically "mutated," so sharing them usually isn’t problematic.

Reassigning a Function
data2.func = function() { return "new function"; };

console.log(data.func());  // "hi"
console.log(data2.func()); // "new function"


👉 After reassignment, the two objects no longer share the same function.

4. Deep Copy with JSON.parse(JSON.stringify())

Creates a new object with no shared references.

Functions and special values (like undefined, Date, Map, etc.) are lost.

let data = { arr: [1, 2, 3], func: () => "hi" };

let data2 = JSON.parse(JSON.stringify(data));

console.log(data2.arr);   // [1, 2, 3] (new independent array)
console.log(data2.func);  // undefined (functions are lost)

✅ Key Rules to Remember

Primitives → always copied by value.

Arrays & Objects → copied by reference in shallow copy.

Mutating the array/object affects both.

Reassigning to a new array/object breaks the shared link.

Functions → reference is copied (shared).

Both objects call the same function unless you reassign a new one.

Deep copy → use JSON.parse(JSON.stringify(obj)) for simple objects (but loses functions).

For complex cases, use libraries like Lodash (_.cloneDeep).

📌 Think of it this way:

Shallow copy = “duplicate the first layer, but inner boxes are still shared.”

Deep copy = “duplicate everything, including inner boxes.”
